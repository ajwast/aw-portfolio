# Alex Wastnidge Portfolio Web App

My personal portfolio and blog written in Typescript with a React frontend, Express backend REST API and Prisma PostgreSQL database. Blog posts and projects are sorted and served from the database via the API to the React app. These are authored and edited via an admin panel accessible via an authenticated user login.

Frontend hosted on Cloudflare [here](https://aw-portfolio-dtq.pages.dev)

Backend is hosted on Render.

The project is offered as open source. You are welcome to clonethe repo, inspect the code or even fork the project as a means to create your own portfolio.
